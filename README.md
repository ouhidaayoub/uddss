# UDDSS 

University Department Decision-Support System

## About

UDDSS is a decision-support system developed for the Computer Science Department of the University of Mohamed El Bachir El Ibrahimi - Bordj Bou Arreridj.

The purpose of the system is to transform official departmental data into reliable indicators, statistics, charts, dashboards, and reports that can help department staff better understand the department and support academic and administrative decision-making.

This project started as a multidisciplinary project proposed by the department head. Instead of treating it as a typical university assignment, I decided to use it as an opportunity to learn and apply software engineering practices through the development of a realistic information system.

## Goals

* Support academic and administrative decision-making.
* Produce reliable indicators and statistics from official data.
* Ensure traceability and trustworthiness of information.
* Apply software engineering practices throughout the project.
* Build a realistic engineering portfolio project.
