# Toolchain

This document defines the official development toolchain for UDDSS.

## Operating System

* Arch Linux (Primary Development Environment)
* WSL2

## Programming Language

* Java 21 LTS

## Build Tool

* Maven

## Database

* MariaDB

## Version Control

* Git
* GitHub

## Development Environment

* Visual Studio Code

## Dependency Repository

* Maven Central Repository

## Required Tools

* Java 21
* Maven
* Git
* MariaDB

## Optional Tools

* Docker
* Notion
* ChatGPT
* Claude

## Secrets

Development:

* `.env`

Deployment:

* Environment Variables
