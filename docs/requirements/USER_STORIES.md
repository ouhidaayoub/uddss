# User Stories

## User Management

This document describes the system from the users' perspective. Each user story captures a goal that a particular type of user wants to achieve and the value gained by accomplishing it. Together, these stories provide a user-centered view of the functional requirements defined in the Software Requirements Specification.

### US-001 Sign In

As a department staff member,

I want to sign in to the system,

So that I can access the information and functionality assigned to my role.

---

### US-002 Access Authorized Features

As a department staff member,

I want to access only the modules and actions I am authorized to use,

So that permissions are enforced consistently.

---

### US-003 Manage User Accounts

As an authorized administrator,

I want to create, modify, activate, and deactivate user accounts,

So that access to the system can be managed effectively.

---

### US-004 Assign Roles and Permissions

As an authorized administrator,

I want to assign roles and configure permissions,

So that users receive the appropriate level of access.

---

## Data Import

### US-005 Import Department Data

As an authorized user,

I want to import departmental data,

So that the system can generate statistics and indicators from official information.

---

### US-006 View Import Results

As an authorized user,

I want to review the results of an import operation,

So that I can verify whether the import completed successfully.

---

### US-007 Prevent Concurrent Imports

As a user,

I want the system to prevent simultaneous import sessions,

So that imported information remains consistent.

---

## Analytics Modules

### US-008 View Student Distribution

As a department staff member,

I want to view student distribution statistics, charts, and indicators,

So that I can better understand the student distribution.

---

### US-009 View Academic Progression

As a department staff member,

I want to view academic progression statistics, charts, and indicators,

So that I can analyze academic outcomes and progression patterns.

---

### US-010 View Administrative Situation

As a department staff member,

I want to view administrative situation statistics, charts, and indicators,

So that I can understand administrative conditions affecting students.

---

### US-011 View Graduation Information

As a department staff member,

I want to view graduation statistics, charts, and indicators,

So that I can analyze graduation-related information.

---

## Dashboard

### US-012 View Dashboard

As a department staff member,

I want to view a dashboard containing information from multiple modules,

So that I can quickly understand the overall state of the department.

---

## Data Management

### US-013 Export Information

As an authorized user,

I want to export statistics, charts, and indicators,

So that I can share or use the information outside the system.

---

### US-014 Create Backups

As an authorized user,

I want to create backups,

So that information can be recovered if necessary.

---

### US-015 Restore Backups

As an authorized user,

I want to restore backups,

So that previously saved information can be recovered.

---

### US-016 Correct Imported Information

As an authorized user,

I want to correct imported information,

So that mistakes can be fixed while preserving historical records.

---

## Auditing

### US-017 Review Audit History

As an authorized user,

I want to review audit history records,

So that important actions can be traced and verified.

---

### US-018 Understand Restricted Information

As a user,

I want to know when information is restricted,

So that I understand why certain information is unavailable.
